## 🌅 ROUTINE MATTUTINA (12 minuti) - OGNI GIORNO

**Obiettivo:** Ridurre rigidità lombare, attivare core, correggere iperlordosi

### Sequenza Esercizi:

1. **Cat-Cow** → 2×15 reps (3" per fase)
   - Enfasi su retroversione nella fase Cat
   - Respiro profondo

2. **Glute Bridge** → 3×12 reps (hold 2" top)
   - Attivazione glutei per proteggere lombare
   - Retroversione bacino prima di sollevare

3. **Dead Bug** → 3×8 per lato
   - Schiena PIATTA a terra
   - Core stabilità

4. **Bird Dog** → 3×8 per lato
   - Movimento lento e controllato
   - Equilibrio e coordinazione

5. **Psoas March** → 2×20 reps
   - Flesso-estensione controllata
   - Attivazione flessori anca

### Tracking:
```
Rigidità PRE: ___/10
Rigidità POST: ___/10
Delta: ___ (target: ≥2 punti)
```

## ⚠️ SISTEMA BANDIERE ROSSE

### 🔴 STOP IMMEDIATO SE:
- Dolore lombare >2/10
- Dolore acuto articolare
- Impossibilità mantenere forma tecnica

### 🟡 RIDUCI CARICO 20% SE:
- Form breakdown >30% esercizi
- Impossibilità mantenere retroversione bacino
- Fatica eccessiva (RPE >8/10 costante)

### 🟢 DELOAD EXTRA 50% SE:
- Rigidità POST > PRE per 2+ giorni consecutivi
- HRV <45ms per 3+ giorni
- ACR >1.5
- Sleep <6h per 3+ giorni

## 🔧 ESERCIZI CHIAVE - QUICK REFERENCE

### LOWER BODY:
1. **Goblet Squat** (Sett 1-4) → **Front Squat** (Sett 5+)
   - Carico: KB o bilanciere davanti
   - Focus: Tronco verticale, retroversione
   - Progressione: +2kg ogni 2 settimane

2. **Trap-Bar Deadlift**
   - Maniglie ALTE (safe lombare)
   - Reset ogni rep
   - Progressione: +3kg ogni 2 settimane

3. **Bulgarian Split Squat**
   - Corpo libero → KB → DB
   - Discesa verticale
   - Focus unilaterale

4. **RDL (Romanian Deadlift)**
   - Cerniera anca
   - Schiena neutra
   - Stretch hamstrings

### UPPER BODY:

5. **Push-Up Variations**
   - Standard → Deficit → Weighted
   - Scapole protrazione top
   - Corpo linea retta

6. **Overhead Press**
   - KB o DB
   - Core tight, no arco lombare
   - Full ROM

7. **Pull-Up Progression**
   - Dead-Hang → Negatives → Full → Weighted
   - Scapole depresse
   - Controllo eccentrica

8. **TRX Row**
   - Corpo linea retta
   - Scapole retrazione
   - Controllo movimento

### CORE SPECIALISTICO:

9. **Plank Weighted**
   - Disco su schiena
   - Retroversione bacino
   - Progressione: peso o tempo

10. **Pallof Press**
    - Anti-rotazione
    - Banda resistenza
    - Core stability

11. **Copenhagen Plank**
    - Adduttori + obliqui
    - Corpo linea retta
    - Hold isometrico

12. **Suitcase Carry**
    - Anti-lateral flexion
    - Postura eretta
    - KB o DB pesante

## 💡 TIPS ALLENAMENTO IN PALESTRA

### TECNICA:
✅ Forma tecnica > Carico sempre
✅ Video check settimanale esercizi principali
✅ Se forma crolla → STOP, riduce carico
✅ Retroversione bacino attiva in OGNI esercizio

### RESPIRAZIONE:
✅ Brace core pre-movimento
✅ Hold durante fase concentrica
✅ Espira nella parte più difficile
✅ Re-brace tra reps negli esercizi pesanti

### PROGRESSIONE:
✅ +2-5% carico ogni 2 settimane (se forma perfetta)
✅ Priorità: reps target → poi aumenta peso
✅ Video confronto per valutare progressi
✅ Non forzare progressione durante deload

### RECUPERO:
✅ Rispetta giorni riposo
✅ Sleep >7h (target 8h)
✅ Hydratazione costante
✅ Nutrition adeguata per peso target
✅ Stretching dedicato nei giorni off

## 📱 STRUMENTI UTILI

### Timer:
- **Tabata:** 20" work / 10" rest × 8 rounds
- **HIIT Standard:** 30" work / 30" rest × 10 rounds
- **Core Circuit:** 45" work / 15" rest × 6 rounds

### Calcoli:
- **Load:** RPE × Durata (minuti)
- **ACR:** Load acuto (7 giorni) / Load cronico (28 giorni)
- **Target ACR:** 0.8-1.3 (sweet spot)
