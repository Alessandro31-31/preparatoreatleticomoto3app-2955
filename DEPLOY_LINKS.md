## 🆘 TROUBLESHOOTING

### Build fallisce?
**Vercel/Netlify cercherà automaticamente di usare Node invece di Bun.**

**Soluzione:**
1. Vai su Settings → Build & Deploy
2. Cambia Build command in:
   ```
   npm install && npx vite build --config vite.config.vercel.ts
   ```

### 404 ancora presente?
**Ricarica con cache vuota:**
- Chrome/Edge: `Ctrl+Shift+R` o `Cmd+Shift+R`
- Safari: `Cmd+Option+R`

### Deploy lento?
- Vercel: 30-90 secondi (normale)
- Netlify: 60-120 secondi (normale)

## 💡 TIPS PRO

### 1. Domini Custom
**Entrambe le piattaforme supportano domini personalizzati GRATIS:**
- Vercel: Settings → Domains → Add
- Netlify: Domain Settings → Add custom domain

**Esempio:**
```
tuodominio.com → redirect alla tua app!
```

### 2. Environment Variables
**Per funzionalità avanzate (auth, database):**

**Vercel:**
- Settings → Environment Variables
- Aggiungi: `VITE_BETTER_AUTH_URL=https://tuosito.vercel.app`

**Netlify:**
- Site settings → Environment variables
- Aggiungi le stesse variabili

### 3. Analytics
**Entrambe le piattaforme offrono analytics gratuiti:**
- Vercel: Automatici (nelle tab Analytics)
- Netlify: Site analytics (attiva in settings)

### 4. Preview Deployments
**Ogni Pull Request ottiene un deploy preview automatico!**
```
PR #1 → https://preparatoreatleticomoto3app-git-feature-vercel.app
```
