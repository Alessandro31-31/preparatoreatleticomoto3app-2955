# ⚡ GUIDA RAPIDA EDITING - 2 Minuti

## 🎯 ACCESSO VELOCE AGLI EDITOR

### ✏️ METODO 1: Dal Contenuto

1. **Apri l'app**
2. **Vai alla schermata** che vuoi modificare:
   - Warmup
   - Cooldown
   - Stretching
   - Foam Rolling
   - Morning Routine
   - etc.
3. **Cerca l'icona ✏️ "Edit"** in alto a destra
4. **Tocca** e modifica!

---

### ⚙️ METODO 2: Da Settings

1. **Apri l'app**
2. **Tocca "Settings"** (ultima tab in basso)
3. **Scegli**:
   - **"Edit Data"** → Modifica tutti i dati
   - **"Content Manager"** → Gestione avanzata

## 🚀 ESEMPIO PRATICO

### Modificare Warmup

**1. Apri Warmup**
```
Home → Warmup
```

**2. Tocca Edit ✏️**
```
(In alto a destra)
```

**3. Modifica:**
- ➕ Aggiungi esercizio
- ✏️ Modifica esistente
- 🗑️ Elimina
- 🔄 Riordina (drag & drop)

**4. Salva**
```
Tocca "Save" in alto
```

**5. Fatto!** ✅

---

## 💾 IMPORT/EXPORT DATI

### Export (Backup)
1. Settings → Content Manager
2. Tocca "Export Data"
3. Salva file JSON
4. Conserva come backup!

### Import (Restore)
1. Settings → Content Manager
2. Tocca "Import Data"
3. Seleziona file JSON
4. Conferma
5. Dati ripristinati!

## 📱 WEB vs APK

### Web App
- ⚠️ Modifiche potrebbero non salvarsi
- ⚠️ Storage limitato browser
- ✅ Testare modifiche rapide

### APK Android
- ✅ Tutte le modifiche salvate
- ✅ Storage completo
- ✅ Import/Export file
- ✅ Backup permanenti

**CONSIGLIO**: Usa APK per editing serio!

## 🆘 RISOLUZIONE PROBLEMI

### ❌ "Non vedo il pulsante Edit"
**Soluzione:**
- Controlla in alto a destra (icona ✏️)
- Oppure vai in Settings → Edit Data

### ❌ "Modifiche non si salvano"
**Soluzione:**
- Su Web: limitazioni browser
- Usa APK Android

### ❌ "Come faccio backup?"
**Soluzione:**
- Settings → Content Manager → Export Data

### ❌ "Voglio modificare il codice"
**Soluzione:**
- Scarica da GitHub
- Modifica file in `mobile-app/`
- Ricompila
