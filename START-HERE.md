# 🏍️ MOTO3 TRAINING PRO - START HERE!

## ⚡ 3 PASSI PER AVERE L'APP SUL TELEFONO

### 📥 PASSO 1: SCARICA
**[CLICK QUI PER SCARICARE](https://github.com/Alessandro31-31/preparatoreatleticomoto3app-2955/archive/refs/heads/claude/moto3-training-app-01K7y3cswB25AaaJBqjVjMx4.zip)**

Estrai il file ZIP in: **`C:\moto3-app`** (importante: niente spazi nel percorso!)

---

### 💻 PASSO 2: APRI POWERSHELL
1. Apri la cartella `C:\moto3-app`
2. Nella barra degli indirizzi (in alto) scrivi: **`powershell`**
3. Premi **Enter**

---

### 🚀 PASSO 3: COPIA E INCOLLA QUESTI COMANDI

```powershell
npm install -g vercel
```
Aspetta che finisca, poi:

```powershell
vercel login
```
Si aprirà il browser → fai login con email o GitHub

Poi:
```powershell
vercel --prod
```

Quando chiede:
- `Set up and deploy?` → premi **Y** e **Enter**
- `Link to existing project?` → premi **N** e **Enter**
- `Project name?` → premi **Enter**
- `Directory?` → premi **Enter**
- `Override settings?` → premi **N** e **Enter**

---

### ✅ FATTO!

Vedrai un messaggio tipo:
```
✅ Production: https://moto3-app-xxxxx.vercel.app
```

**QUEL LINK È LA TUA APP!** 🎉

Aprilo dal telefono e aggiungi alla home screen:
- **iPhone**: Safari → Condividi → "Aggiungi a Home"
- **Android**: Chrome → Menu → "Aggiungi a Home"
